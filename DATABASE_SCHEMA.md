## Entity overview

```
auth.users 1─1 profiles 1─* posts 1─* post_images
                  │           │  *─* tags (post_tags)
                  │           │  1─* likes, comments, saved_posts, collection_items
                  │           └─* categories (primary, subcategory, cuisine, meal_type, dish_type)
                  ├─* follows (follower → following)
                  ├─* collections 1─* collection_items
                  ├─* user_blocks
                  └─* reports
```

## Tables

### profiles
| column | type | notes |
| --- | --- | --- |
| id | uuid PK → auth.users | cascade delete |
| username | text unique | `^[a-z0-9_.]{3,24}$`, no leading/trailing/double dots |
| display_name | text | 1–50 chars |
| bio | text | ≤160 |
| avatar_path | text null | path in `avatars` bucket |
| created_at / updated_at | timestamptz | trigger-maintained |

### categories (taxonomy)
| column | type | notes |
| --- | --- | --- |
| id | uuid PK | |
| kind | text | `primary`, `subcategory`, `cuisine`, `meal_type`, `dish_type` |
| parent_id | uuid null | required iff kind = subcategory |
| slug | text | unique per (kind, parent) |
| name, sort_order, is_active | | |

Primary categories: cooking, baking, drinks. Baking and Drinks have
subcategories; Cooking's quick pick is cuisine.

### posts — one row per cooking *attempt*
| column | type | notes |
| --- | --- | --- |
| id | uuid PK | generated by the client so images can upload first |
| author_id | uuid → profiles | cascade |
| title | text | 1–80, trimmed |
| primary_category_id | uuid → categories | must be kind `primary` |
| subcategory_id | uuid null | must be a child of the primary |
| cuisine_id, meal_type_id, dish_type_id | uuid null | kind-checked by trigger |
| rating | numeric(3,1) null | 0.0–10.0; required unless draft |
| review | text | ≤2000 |
| visibility | text | `public` \| `followers` \| `private` |
| status | text | `draft` \| `published` |
| made_on | date | default today; not in the future (RPC check) |
| would_make_again | bool null | |
| recipe_url | text null | http(s) only, ≤500 |
| ingredients, prep_notes, next_time_notes | text | length-capped |
| cook_time_minutes | int null | 1–2880 |
| temperature | text null | `hot` \| `iced` |
| milk, sweetener | text null | ≤40 |
| like_count, comment_count | int | trigger-maintained, not client-writable |
| published_at | timestamptz null | set on first publish, kept on edit, cleared for drafts |

Indexes: feed `(author_id, published_at desc, id desc) where published`, diary,
rankings `(author_id, rating desc, made_on desc)`, recent, per-taxonomy, trigram on
title.

### post_images
`id, post_id, storage_path, thumb_path, width, height, position (0–9)`;
`unique(post_id, position) deferrable` so reorders happen in one transaction.

### tags / post_tags
`tags(id, slug unique, name, created_by)`. Slugs are normalized by
`public.slugify()`, so "Oat Milk", "oat-milk" and " oat milk " are one tag.

### follows
PK `(follower_id, following_id)`; `check follower_id <> following_id`.

### likes
PK `(user_id, post_id)` → a user can like a post once.

### comments
`id, post_id, author_id, body (1–1000 trimmed), created_at, updated_at`.

### saved_posts
PK `(user_id, post_id)`. Private to the saver.

### collections / collection_items
`collections(id, owner_id, name, description, visibility public|private)`,
unique name per owner (case-insensitive). Items PK `(collection_id, post_id)`.

### user_blocks
PK `(blocker_id, blocked_id)`; insert trigger deletes follows both ways.

### reports
`reporter_id, target_type (user|post|comment), target_*_id, reason, details,
status`. Targets set null on deletion so the report survives.

## Visibility rule

`public.can_view_post(author_id, visibility, status)`:

1. Not signed in → no.
2. Your own post → yes (including drafts and private).
3. Draft → no.
4. Either side has blocked the other → no.
5. `public` → yes. `followers` → only if you follow the author. `private` → no.

Child tables (images, tags, likes, comments, saves, collection items) and the
`post-images` Storage bucket require their parent post to be selectable, so this
one function governs all of them.

## RLS summary

| Table | Select | Insert | Update | Delete |
| --- | --- | --- | --- | --- |
| profiles | all, unless owner blocked you | self | self (cols) | self |
| categories | all | — | — | — |
| posts | `can_view_post` | author = you | author (cols) | author |
| post_images | parent visible | author, own folder | author (`position`) | author |
| tags | all | `created_by` = you | — | — |
| post_tags | parent visible | author | — | author |
| follows | all | you, not blocked | — | follower or followee |
| likes | parent visible | you, post visible & published | — | you |
| comments | parent visible, not blocked | you, post visible & published | author (`body`) | author or post author |
| saved_posts | you | you, post visible | — | you |
| collections | owner, or public & not blocked | owner | owner (cols) | owner |
| collection_items | collection & post visible | collection owner, post visible | — | collection owner |
| user_blocks | blocker | blocker | — | blocker |
| reports | reporter | reporter | — | — |

`anon` has no table access at all.

## RPCs and computed fields

| Function | Purpose |
| --- | --- |
| `feed_posts(p_before, p_before_id, p_limit)` | following feed (+ own posts), keyset |
| `discover_posts(p_sort, filters…, cursor/offset)` | discover grids (`recent`, `top`, `loved`) |
| `search_posts(p_query, cursor)` | name / tag / category search |
| `trending_taxonomy(p_since, p_min_posts, p_limit)` | categories/tags with real recent posts |
| `suggested_cooks(p_limit)` | people to follow |
| `profile_stats(p_user_id)` | follower/following/post counts by primary |
| `get_rankings(p_user_id, filters…, p_sort, p_limit, p_offset)` | ranked list |
| `ranking_filters(p_user_id)` | filter chips the user actually used |
| `save_post(p_post, p_images, p_tags)` | transactional create/update |
| `username_available(p_username)` | onboarding check |
| `delete_account()` | deletes the caller's auth user (cascades) |
| `viewer_has_liked(posts)`, `viewer_has_saved(posts)` | computed columns |
| `viewer_is_following(profiles)`, `viewer_has_blocked(profiles)` | computed columns |

## Storage

| Bucket | Public | Path | Read | Write |
| --- | --- | --- | --- | --- |
| `avatars` | yes | `{uid}/{uuid}.jpg` | anyone | owner folder |
| `post-images` | no | `{uid}/{postId}/{imageId}.jpg` + `_thumb.jpg` | owner, or anyone who can see a referencing post | owner folder |
